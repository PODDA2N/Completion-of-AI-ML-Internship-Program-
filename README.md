# Completion-of-AI-ML-Internship-Program-

I am delighted to share my experience with the AI/ML internship program at Labmentix. During this internship, I had the opportunity to work on around ten industry-oriented projects that significantly enhanced my technical and analytical skills.

Some of the major projects I worked on include Zomato Restaurant Review Analysis, Shopper Spectrum for customer segmentation and product recommendations in e-commerce, Tourism Experience Analytics, DeepCSAT for customer satisfaction prediction, PhonePe Transaction Insights, and an AI-based Text Summarization Platform.

I also gained hands-on experience in deep learning projects such as Aerial Object Classification and Detection using YOLOv8, Tesla Stock Price Prediction using SimpleRNN and LSTM, and an Agentic AI-based Travel Planning Assistant using LangChain.

Throughout the internship, expertise in machine learning model development, deep learning architectures and AI based application building, utilized tools and frameworks such as TensorFlow, Keras, Py-Torch and scikit-learn to solve real world problems.
